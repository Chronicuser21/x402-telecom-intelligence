🤖 Telecom SIP Intelligence for AI Agents

Specialized telecom/SIP intelligence tools for AI agents in NOC operations, VoIP monitoring, and telecom automation.

Available Endpoints

🎁 FREE - Phone Normalization

POST /api/v1/tools/phone-normalize

Validate and normalize phone numbers to E.164 format. Detect line types (mobile, landline, toll-free) and country codes.

💰 $0.01 - SIP Decode

POST /api/v1/tools/sip-decode

Parse SIP protocol messages into structured JSON with telecom domain expertise.

💰 $0.02 - Call Diagnose

POST /api/v1/tools/call-diagnose

Analyze SIP traces to diagnose VoIP call failures with specialized telecom expertise.

💰 $0.005 - Phone Info

POST /api/v1/tools/phone-info

Get comprehensive phone number information including carrier detection and line type analysis.
