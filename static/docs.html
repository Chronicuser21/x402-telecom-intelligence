API Endpoints

POST /api/v1/tools/phone-normalize $0.001

Normalize raw phone strings into standardized formats (E.164, international, national, RFC3966 URI). Includes line type detection (mobile, landline, toll-free).

// Input
{
  "raw_string": "+14155552671",
  "region": "US",
  "target_format": "e164"
}

// Output
{
  "status": "success",
  "valid": true,
  "line_type_hint": "MOBILE",
  "formatted_result": "+14155552671"
}
POST /api/v1/tools/sip-decode $0.005

Parse raw SIP messages into structured JSON. Handles RFC 3261 compact headers, folded headers, multi-value headers, and both request/response messages.

// Input
{
  "rawSipMessage": "INVITE sip:bob@biloxi.com SIP/2.0\r\nVia: SIP/2.0/UDP pc33.atlanta.com\r\nFrom: Alice"
}

// Output
{
  "status": "success",
  "data": {
    "type": "request",
    "method": "INVITE",
    "uri": "sip:bob@biloxi.com",
    "headers": {
      "Via": "SIP/2.0/UDP pc33.atlanta.com",
      "From": "Alice"
    }
  }
}
POST /api/v1/tools/call-diagnose $0.01

Automated forensics analyzer for VoIP call failures. Analyzes SIP traces and provides ranked diagnostic hypotheses with remediation steps.

// Input
{
  "sipTrace": "INVITE sip:alice@atlanta.com SIP/2.0\n...\nSIP/2.0 487 Request Terminated"
}

// Output
{
  "status": "success",
  "data": {
    "assessment": "NORMAL",
    "hypotheses": [
      "Normal call termination — one side cancelled the request before the far end answered."
    ],
    "remediation": "No infrastructure fix required. If unintended, check application logic that triggers CANCEL."
  }
}
